# my — 세팅 중 내 자료를 두는 곳

이 폴더의 내용은 **깃에 올라가지 않는다.** (`.gitignore`로 막혀 있다) 개인 자료를 마음 놓고 넣어도 된다.

세팅이 끝나면 정리된 설정은 내 컴퓨터의 스킬 폴더(`~/.claude/skills/pt-deck/profile.md`)로 들어간다. 여기 남는 파일은 세팅 기록이다. 지워도 스킬에는 영향이 없다.

## 넣을 것

| 무엇 | 어디에 | 왜 |
|---|---|---|
| 예전에 만든 발표자료 (PDF·PPT·이미지) | `samples/` | 내 시각·구조 패턴을 읽어낸다 |
| AI 없이 직접 쓴 글 (보고서·메일·블로그 등) | `samples/` | 내 말투 기준선을 잡아 오판을 막는다 |
| 조직 템플릿 파일 | `samples/` | 양식이 정해져 있으면 그것이 우선한다 |

파일을 넣은 뒤 클로드코드에 "넣었어요"라고 하면 읽고 정리한다.

## 세팅이 여기 만드는 파일

| 파일 | 내용 |
|---|---|
| `00_프로파일.md` | 아래 넷을 요약한 것. 스킬 폴더에 `profile.md`로 복사된다 |
| `01_내_PT_패턴.md` | 기존 자료에서 읽어낸 패턴 |
| `02_내_제작원칙.md` | 본인·조직의 규칙 |
| `03_내_말투.md` | 문장 기준선과 보호 목록 |
| `04_목적과_타겟.md` | 누구에게 무엇을 만드는가 |

빈 양식은 `../blueprints/profile_templates/`에 있다. 직접 채워 넣어도 된다.

## 만든 뒤에 바꾸고 싶을 때

- 설정 일부: 어느 폴더에서든 `/PT설정`
- 자료 추가: `/PT설정`에서 "이 파일 읽고 반영해줘"
- 처음부터 다시: 이 `pt-deck-kit` 폴더를 열고 말을 건다
